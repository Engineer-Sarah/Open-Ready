# Contributing to OpenReady

Thanks for your interest in improving OpenReady! Beginners are very welcome.

## Getting started
1. Fork the repository and clone your fork.
2. Install dependencies with `npm install`.
3. Copy `.env.example` to `.env.local` (all values are optional).
4. Start the dev server with `npm run dev` and open http://localhost:3000.

## Making a change
1. Create a branch: `git checkout -b my-change`.
2. Make your change and run `npm run lint`.
3. Open a pull request that explains what you changed and why.

## Ideas for contributions
- New readiness checks (for example CODE_OF_CONDUCT or issue templates)
- Better detection of secrets in file contents
- Translations of the fix guides
- Tests for the scoring logic in `lib/audit.ts`

## Reporting bugs
Open an issue with the repository you checked and what you expected to see.

## Code of conduct
Be kind and respectful to everyone.
