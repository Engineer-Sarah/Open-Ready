# Contributing to OpenReady

Thanks for your interest in improving OpenReady! Beginners and first-time contributors are very welcome.

## Getting Started
1. Fork the repository and clone your fork.
2. Install dependencies with `npm install`.
3. Copy `.env.example` to `.env.local` (all values are optional for local audits).
4. Start the development server with `npm run dev` and open http://localhost:3000.

## Making a Change
1. Create a feature branch: `git checkout -b my-feature`.
2. Make your improvements and test them locally.
3. Open a pull request that clearly explains your changes.

## Areas for Contribution
- Additional readiness checks (e.g., Code of Conduct, Issue templates).
- Deeper AST scanning for accidental secrets inside code files.
- UI enhancements and internationalization of fix guides.

## Code of Conduct
Be kind, respectful, and supportive to everyone in the community.
